#Proyecto Sencillo

Proyecto sencillo creado utilizando HTML y CSS a modo de practica para el ramo de Frontend de la universidad

## Descripción

Página echa a modo de practica que cuenta con información básica acerca del videojuego "Doom" (1993)

## Estructura del proyecto

├── index.html        # Estructura principal del sitio web
├── style.css         # Estilos visuales
├── doomguy.png       # Imagen del personaje principal
├── cacodemon.png     # Imagen del Cacodemon
└── README.md         # Documentación del proyecto

## Ejecución del proyecto

1. Clonar o descargar el proyecto desde Github.
2. Doble click en index.html para ejecutarlo en cualquier navegador web

## Herramientas Utilizadas

- HTML
- CSS
